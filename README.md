# PRONA Board MCP

**Бесплатная доска-холст, на которой ИИ-агент ведёт сложную задачу по этапам.** Подключите Claude Code, Codex или Cursor к [PRONA Board](https://prona.space/board) по MCP. Агент идёт по треку методики, а решения и вопросы к вам сразу видны на доске.

Бесплатно · без регистрации · удалённый MCP-сервер, устанавливать ничего не нужно

[Открыть PRONA Board](https://prona.space/board) · [Документация](https://prona.space/board/docs)

> В этом репозитории лежат описание и инструкция по подключению. Сервер удалённый (Streamable HTTP) и работает на стороне PRONA: `https://board-mcp.prona.space/mcp`.

---

## Зачем доска, а не чат

В чате решения агента тонут в тексте. На доске они на виду:

- **Принятое и отвергнутое лежит на стикерах** рядом друг с другом, и у каждого своя причина.
- **Спорное агент выносит вопросом к вам.** Варианты лежат рядом, и вопрос приходит, пока работа не ушла дальше.
- **Путь задаёт трек, а не формулировка.** Агент идёт по этапам и подстраивает их под задачу.

## Как это работает

1. **Подключите агента** одной командой или строкой в конфиге (см. ниже).
2. **Дайте задачу своими словами**, как коллеге. Например: «Разберись, почему новые клиенты не возвращаются, и разложи разбор на доске».
3. **Отвечайте на вопросы.** Агент идёт по этапам и выкладывает всё на доску. Вы уточняете, возвращаетесь назад и меняете решение прямо на холсте.

## Треки методики

| Трек | Для кого | Этапы |
|---|---|---|
| **Исследование** | продакт, аналитик, маркетолог | контекст и проблема → цель и ценность → как есть сейчас → сценарии и истории → критерии приёмки и DoD → риски и неизвестные → скоп работ и DoR |
| **Разработка** | разработчик, тимлид, аналитик | детализация → разведка кода → опорные примеры → замеры «до» → замысел и контракты → нарезка на задачи → проверка → разбор дефекта → выкатка и наблюдение |
| **Документация** | техписатель, методист, автор регламентов | читатель и его вопрос → инвентарь и правда → жанр и состав → принципы и критерии → вывод среза «Замысел» → разрез на блоки и письмо → вывод среза «Письмо» → утверждение и жизнь |

**Библиотека методов:** пять «почему», диаграмма Ишикавы, Impact Map, карта историй, матрица рисков, ADR и другие.

## Подключение

### 1. Получите токен

Откройте [prona.space/board](https://prona.space/board) и нажмите **«Подключить агента»**. Выберите клиент и срок токена (7 дней, 30 дней или бессрочно) и скопируйте готовую конфигурацию: токен в ней уже подставлен.

> Один токен открывает агенту все доски вашего пространства. Не публикуйте его и не коммитьте в репозитории.

### 2. Добавьте сервер в клиент

**Claude Code**

```bash
claude mcp add --transport http prona-board https://board-mcp.prona.space/mcp --header "Authorization: Bearer <ТОКЕН>"
```

Проверка: `claude mcp list`.

**Codex** — `~/.codex/config.toml` (в Windows — `%USERPROFILE%\.codex\config.toml`):

```toml
[mcp_servers.prona-board]
url = "https://board-mcp.prona.space/mcp"
http_headers = { "Authorization" = "Bearer <ТОКЕН>" }
```

Перезапустите Codex. Проверка: `codex mcp list`.

**Cursor** — `~/.cursor/mcp.json` (для всех проектов) или `.cursor/mcp.json` (для одного проекта):

```json
{
  "mcpServers": {
    "prona-board": {
      "url": "https://board-mcp.prona.space/mcp",
      "headers": { "Authorization": "Bearer <ТОКЕН>" }
    }
  }
}
```

**Другие MCP-клиенты**

```json
{
  "mcpServers": {
    "prona-board": {
      "type": "http",
      "url": "https://board-mcp.prona.space/mcp",
      "headers": { "Authorization": "Bearer <ТОКЕН>" }
    }
  }
}
```

### 3. Попросите агента создать доску

Если доска появилась в списке на [prona.space/board](https://prona.space/board), связь есть и можно работать.

## Инструменты

Шесть инструментов по назначению. Действие внутри инструмента выбирается полем `op`. Координаты агент не считает: он говорит, что и относительно чего поставить, а раскладку, зазоры и обход связей считает сервер.

| Инструмент | Назначение | Операции (`op`) |
|---|---|---|
| `board_read` | Читать доску сценой, а не плоским списком фигур. Показывает, что изменилось с прошлого чтения и что правил человек | `overview`, `frame`, `elements`, `full`, `index`, `spatial`, `connectors`, `layout_map`, `changes`, `diff`, `document`, `selection`, `image`, `frame_shot`, `mockup_shot`, `storyboard`, `animation` |
| `board_create` | Создавать: секцию (сервер сам измерит, разложит и обведёт областью), элементы и связи пачкой, шаблоны с зонами (канбан, 2×2, карта историй), план по треку методики, раскадровку показа, видеоанимацию | `section`, `elements`, `template`, `place`, `frame`, `measure`, `method` (он же `research`), `storyboard`, `animation` |
| `board_arrange` | Раскладывать и прибирать то, что уже на доске | `arrange`, `align`, `move_group`, `move`, `fit`, `resize`, `membership` |
| `board_edit` | Править существующее: текст, цвет, статусы, тело документа, слой, таблицы, макеты. Копировать и удалять | `update`, `copy`, `delete`, `track_choice` |
| `board_safety` | Точки возврата и замки: версия перед крупной правкой, замок на область на время серии правок | `save_version`, `list_versions`, `lock`, `unlock`, `locks` |
| `board_space` | Доски пространства и проверка связи. Одна задача — одна доска | `status`, `boards`, `new_board`, `drop_board` |

Кроме инструментов, сервер отдаёт MCP-промпт `board_task_workflow`: правила ведения доски задачи.

Каждая запись сверяется с ревизией доски. Если человек успел что-то поменять, агент получит отказ `stale_revision` и не перезапишет чужую работу. В каждом ответе записи видно, применилась ли правка (`applied`).

## Данные и хранение

- **Агент работает на вашей стороне.** Код, репозиторий, данные проекта и переписка с агентом остаются у вас. В PRONA уходит только то, что агент выкладывает на доску: стикеры, текст, таблицы.
- **Где лежат доски.** В хранилище PRONA или в вашем: Supabase, S3, GitHub. Агент видит только те доски, к которым вы дали доступ.
- **Без аккаунта.** Доступ к пространству хранится в браузере и может потеряться при очистке его данных. Чтобы не потерять доски, скачайте их файлом `.pronaboard`, подключите своё хранилище или используйте полную версию PRONA.

## Стоимость

Бесплатно: до 30 досок по 20 МБ и базовая совместная работа (команда до 10 человек по ссылке). Полная облачная и коробочная версии — по запросу на [prona.space](https://prona.space).

## Чем отличается от Miro и Deep Research

Miro — холст, который вы заполняете сами. Deep Research выдаёт готовый отчёт без вашего участия по ходу работы. В PRONA Board агент ведёт задачу по этапам, а вы на каждом этапе уточняете, возвращаетесь и меняете решение прямо на доске.

## English

**PRONA Board** is a free canvas where your AI agent runs a hard task stage by stage. Connect Claude Code, Codex or Cursor over MCP. The agent follows a method track (Research, Delivery, Documentation), and its decisions and questions for you are right there on the board. It's free and needs no sign-up.

- Remote MCP server (Streamable HTTP): `https://board-mcp.prona.space/mcp`, auth `Authorization: Bearer <token>`
- Tools: `board_read`, `board_create`, `board_arrange`, `board_edit`, `board_safety`, `board_space` (action picked by the `op` field) + prompt `board_task_workflow`
- Get a token: [prona.space/board](https://prona.space/board) → **Connect an agent**
- Docs: [prona.space/board/docs](https://prona.space/board/docs)
